# HotspotSSIDChanger

A **rootless jailbreak tweak for iOS 16** that lets you set a custom hotspot SSID without changing your device name.

## Features

-  Custom hotspot SSID
-  iOS 16 + rootless jailbreak support
-  Integrated into the hotspot settings menu 
  

> **Note:** The tweak hooks into `wifid`, which I think it only handles the hotspot name, if I'm wrong please make an issue about it and I will try to find another service to hook the custom name too. The device name in settings does **NOT** change.

## Compatibility

iOS 16.x.x is currently the targeted version, future updates will include iOS 15, iOS 17, 18 and possibly iOS 26 support.


All iOS 16 devices are fully compatible as the tweak now hooks `wifid` instead of `sharingd`.
iOS 15, 17, 18 and 26 is possible but not implemented yet, I won't be able to test iOS 17, 18 or 26 properly as I do not have a device on any of these versions.
