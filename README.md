# HotspotSSIDChanger

A **rootless jailbreak tweak for iOS 16** that lets you set a custom hotspot SSID without changing your device name.

## Features

-  Custom hotspot SSID
-  iOS 16 + rootless jailbreak support
-  Integrated into the hotspot settings menu 
  

> **Note:** The tweak hooks into `sharingd`, which also handles AirDrop and some other services. Because of this, the custom name will also appear on services that use sharingd. The device name in settings does **NOT** change.

## Compatibility

iOS 16.x.x is currently the targeted version, future updates will include iOS 17, 18 and possibly iOS 26 support.


Compatibility may vary between iOS 16 versions due to changes in Apple's `sharingd` implementation.
